# GymBro 🏋️

Веб-приложение для отслеживания тренировок, веса и прогресса в фитнесе.

## 📋 О проекте

GymBro - это многофункциональное Spring Boot приложение для управления вашими фитнес-активностями. С помощью приложения вы можете:

- 📝 Создавать тренировки
- 💪 Использовать базовые упражнения и добавлять пользовательские
- 📊 Анализировать статистику прогресса
- ⚖️ Отслеживать изменения веса тела и получать рекомендации
- 🔐 Безопасно хранить данные с авторизацией

## 🚀 Быстрый старт

### Предварительные требования:
- **Docker**
- **Docker Compose**

### Запуск:
```bash
git clone https://github.com/rsvtalk/gymbro.git
cd gymbro
docker-compose up
```

## 🛠 Технологии

- **Backend:** Spring Boot 3.5.5, Spring Security, Spring Data JPA
- **Frontend:** Thymeleaf, HTML/CSS (улучшен с помощью AI)
- **Database:** PostgreSQL
- **Authentication:** Spring Security с BCrypt
- **Build Tool:** Maven
- **Java:** 21

## 📊 Функциональность

- **Мои тренировки** - создавайте новые тренировки, просматривайте историю со статистическими данными, удаляйте тренировки по необходимости
- **Статистика по упражнениям** - отсматривайте детальную статистику по каждому упражнению
- **Библиотека упражнений** - используйте стандартные упражнения или создавайте кастомные
- **Контроль веса** - фиксируйте изменения веса и получайте персонализированные рекомендации по калориям
- **Настройки** - изменяйте личные данные и единицы измерения (кг/фунты, см/футы)
